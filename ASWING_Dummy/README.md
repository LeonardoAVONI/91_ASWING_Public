## 0. Introduction

ASWING is an aerodynamic/structural analysis software originally developed by **Mark Drela at MIT**.  
For more information, visit the [official ASWING webpage](https://web.mit.edu/drela/Public/web/aswing/).

This repository **does not contain ASWING**, but just the install methods to use if one already has access to the ASWING software.
All the folders containing usually ASWING data have been emptied. Those folders are labeled as `xxx_dummy`

---

## 1. Dummy Folder Structure

The ASWING repository is usually organized as follows:

~~~
ASWING_Repository/
├── src/                     # ASWING Fortran source
├── plotlib/                 # Plotlib source
├── bin/                     # Executable output
├── test_run/                # Test folder
├── documents_and_manuals/   # Original MIT documents
├── install_and_uninstall/   # Renewed install and uninstall guides
├── ...

~~~
For the sake of including the install and test run instructions to users, without publishing ASWING code, most folders have been emptied.

## 2. Additional Information

For detailed instructions, see the respective files in `install_and_uninstall` or the original MIT manuals in `documents_and_manuals`.

The `test_run` folder can be used to verify that the ASWING build works correctly.
